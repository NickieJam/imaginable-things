# Imaginable OS 7.0 — Unified App Shell

This update does not modify leads, jobs, customers, portfolio, photos, or website data.

It adds:
- one navigation sidebar across Dashboard, Lead Inbox, Job Tracker and Customer Hub
- a phone-friendly menu
- direct links between the four business modules
- permanent shortcuts to Pages CMS and the public website
- Dashboard version 7.0.0

Installation:
1. Copy the contents of this ZIP into the project root.
2. In CMD, from the project folder, run:
   node apply-v7.js
3. Run:
   git status
4. Do not commit until the status is reviewed.

The installer only adds the shared CSS/JS references to the four existing admin HTML files.
