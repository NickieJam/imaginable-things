# Imaginable OS 7.1 — Global Search + Quick Actions

Adds global search across Leads, Jobs and Customers plus a Quick Add launcher available from every Imaginable OS screen.

## Safety
This update does not modify leads, jobs, customers, portfolio, Blob storage, or quote upload/download data.

## Install
1. Copy all files from this package into the project root.
2. Run: node apply-v7-1.js
3. Run: git status
4. Review status before committing.

Expected modified files:
- admin/index.html
- admin/leads.html
- admin/jobs.html
- admin/customers.html

Expected new files:
- admin/global-tools.css
- admin/global-tools.js
- apply-v7-1.js
- VERSION-7.1-GUIDE.md
