# Imaginable OS 7.3-B — Payment Status Cards

Adds payment visibility directly to every Job Tracker card.

Shows:
- Payment status
- Order total
- Amount paid
- Balance due

This update is read-only and uses payment data already saved by 7.3-A.

Install:
1. Copy package files into the project root.
2. Run: node apply-v7-3b.js
3. Run: git status
4. Do not commit or push until reviewed.
