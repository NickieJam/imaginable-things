# Imaginable OS 7.2-A — Activity & Needs Attention

Adds Dashboard panels for Needs Attention and Recent Activity.

Safety:
- Does not modify quote uploads/downloads.
- Does not modify payments.
- Reads existing Lead/Job JSON data only.

Install:
1. Copy these files into the project root.
2. Run: node apply-v7-2a.js
3. Run: git status
4. Do not commit or push until the Dashboard is tested.
