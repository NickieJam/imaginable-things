# Imaginable Things 7.4-B — Final Proof Approval

This package adds the first complete customer approval workflow.

## What it adds

### Imaginable OS / Job Tracker
Each Job card receives:
- Proof Approval button
- NO APPROVAL / APPROVAL PENDING / CUSTOMER APPROVED indicator
- Approval management modal

The modal lets the admin set:
- customer approval name
- proof version
- direct proof image/PDF URL
- customer-facing order/proof notes
- Admin PIN

A secure customer approval link is generated by the server.

### Customer approval page
`/approval.html?token=...`

The customer can:
- see the Job number
- see product, quantity, technique and due date
- see the exact proof version
- view the proof image/PDF
- review written order/proof notes
- type their name
- affirm the approval statement
- approve for production

### Evidence saved with the Job
The Job stores:
- approval record ID
- status
- recipient name
- proof version and URL
- proof/order notes
- policy version
- proof fingerprint (SHA-256)
- request timestamp
- approval timestamp
- approval method
- hashed typed-name evidence
- prior approvals in approval_history when a revised proof is issued

The raw secure customer token is NOT stored in the public jobs data. Only its
SHA-256 hash is stored. The raw link is kept in the admin browser's local
storage for convenience. If the admin browser loses the link, issuing a new
link invalidates the old one.

## Important
7.4-B expects 7.4-A (`/custom-order-policy.html`) to already be installed.

For this first version, the final proof is supplied as a direct image or PDF
URL. A future step can connect the proof workflow directly to the existing file
upload/storage system.

## Install
Copy the package contents into the project root and run:

`node apply-v7-4b.js`

Then review with `git status` before committing.
